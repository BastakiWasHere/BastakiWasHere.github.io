# Bastaki — Data & Human Space

A static course website ready for GitHub Pages.

## Publish it

1. Create a **public** GitHub repository named `BastakiWasHere.github.io`.
2. Upload these files to the repository's main branch.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. The live site will be available at `https://bastakiwashere.github.io` after GitHub finishes building it.

To change the writing later, edit `index.html`. The colors and layout are in `styles.css`.
